# Trade Journal (prototype)

A clickable prototype of the Trade Journal site with sample data.

## Pages
- `index.html`: Dashboard
- `trades.html`, `import.html`, `insights.html`, `pricing.html`
- `ideas.html`, `leaderboard.html`, `awards.html`, `rules.html`, `trophies.html`, `profile.html`

## Publish with GitHub Pages
1. Create a new repository on GitHub and upload every file and the `vendor` folder (keep the folder structure).
2. Go to Settings → Pages.
3. Under "Build and deployment," choose "Deploy from a branch," pick `main` and `/ (root)`, then Save.
4. After a minute or two, the site is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.

Everything runs in the browser. There is no server and no build step.
`vendor/react-bundle.js` is React 19 (MIT license) bundled into one file.
